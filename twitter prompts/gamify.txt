# Discipline RPG – Gamified Habit Builder (Web-Based Game)

## Overview
A complete, interactive HTML-based web game that gamifies discipline and habit building. The app runs offline, with no external dependencies—just open the HTML file in any browser.

---

## 1. Game Mechanics

### 🎮 Character Progression System

- **Leveling System**
  - Players start at Level 1
  - Gain XP by completing tasks
  - Each level requires ~20% more XP than the last  
    - Example: Level 1 → 2 = 100 XP, Level 2 → 3 = 120 XP

- **Currency System**
  - Earn **Gold Points (GP)** by completing tasks
  - Spend GP in the reward shop

- **Visual Progress**
  - Animated XP bars
  - Clear level indicators

---

## 2. Quest and Task Structure

### 🧩 Task Categories

#### Daily Quests (3–7 XP each)
- Morning routine completion
- Focused work session (1+ hrs)
- Physical exercise
- Healthy meal preparation
- Reading or learning
- Digital detox
- Cleaning / organizing

#### Weekly Boss Battles (15–25 XP each)
- Skill/project milestones
- Long-term goal progress
- Major achievements

#### Micro Habits (1–3 XP each)
- Drink water
- Take vitamins
- Gratitude journaling
- Sleep adherence
- Meditation session

---

## 3. Streak and Achievement System

### 🔥 Streak Counters
- Track streaks per habit
- Visual display of current streaks

### 🏅 Achievement Badges
- Examples: First Quest Completion, 7-day, 30-day, 100-day streaks
- Badge tiers: 5, 10, 20 completions
- Badge display with icons and hover descriptions

---

## 4. Reward Shop System

### 🎁 Exchange GP for Real-World Rewards

- **Low-Cost (10–30 GP)**: Favorite snack, entertainment
- **Medium (40–75 GP)**: Movie night, hobby time, restaurant visit
- **High-Value (100+ GP)**: Full day off, major experience

---

## 5. Data and Engagement Logic

### 💾 Data Persistence
- Use `localStorage` to save all progress
- Works offline (fully client-side)

### 🔄 Daily Reset Logic
- Daily quests reset automatically each calendar day

### 📈 Streak Protection
- Maintain streak if tasks completed across consecutive days

### 📊 Statistics Tracked
- Quests completed
- Longest streaks
- Total XP earned
